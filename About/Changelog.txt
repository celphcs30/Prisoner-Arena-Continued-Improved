- Implemented caching system for overlay calculations (only recalculates when settings change)

- Eliminated per-frame memory allocations
- Removed support for RimWorld 1.0-1.5 (1.6 only)
- Updated mod name to "Prisoner Arena (Continued) - Upgraded" for consistency
